## 🚀 Quick Start Commands

### **1. Create This Configuration:**
```bash
curl -X POST http://localhost:4000/clients \
  -H "Content-Type: application/json" \
  -d @nu-skin-config.json
```

### **2. Create Your Agent:**
```bash
curl -X POST http://localhost:4000/agents \
  -H "Content-Type: application/json" \
  -d '{
    "client_id": 1,
    "name": "Nu Skin Freedom Builder",
    "auto_start": false
  }'
```

### **3. Find First Prospects:**
```bash
curl -X POST http://localhost:4000/prospects/simulate-search \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": 1,
    "count": 20
  }'
```

### **4. Get Priority Prospects:**
```bash
curl http://localhost:4000/scoring/priority-prospects?limit=20&minScore=70
```
